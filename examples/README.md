# CRS Example Programs

These small programs are written in CRS syntax and are intended as reference material for language behavior, parser fixtures, and future integration tests.

Suggested use:

- Keep examples valid as the language evolves.
- Promote examples into automated tests when a feature becomes stable.
- Prefer small programs that demonstrate one idea clearly.

Current examples:

- `hello_world.crs`
- `fizz_buzz.crs`
- `factorial.crs`
- `fibonacci.crs`
- `arrays_and_slices.crs`
- `objects_and_methods.crs`
- `namespaces.crs`
- `conversions.crs`
